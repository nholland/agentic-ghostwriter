# Respect as a Resource

Respect is a finite resource — a boundary that represents access to other
resources (time, energy, reputation, status). When respect is challenged, the
anger mechanism activates for the same reason it activates when any resource is
threatened. This makes anger around respect evolutionarily coherent, not
irrational. Understanding this is the honest entry point into the chapter on
anger: the mechanism isn't broken, it's misdirected.
