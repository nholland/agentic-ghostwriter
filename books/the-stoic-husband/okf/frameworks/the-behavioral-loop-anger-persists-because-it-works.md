# The Behavioral Loop (Anger Persists Because It Works)

Anger continues because it gets results — compliance, submission, the argument
ending. As long as the marriage doesn't end, the negative feedback loop never
fires. The blueprint was inherited because it wasn't punished. Men who modeled
this behavior likely saw it work by narrow metrics (restored compliance, no
divorce). The behavior changes only when consequences become large enough to
activate the negative loop — which historically required rock bottom.

# Schema

- **Modern variable:** Women have more economic and social power now; divorce is
  a more executable consequence than previous generations. This is why the anger
  blueprint is under more pressure now than it was.
- **Key insight:** "It worked. That's why you inherited it." This must be
  acknowledged before the chapter can earn its argument.
