# The Stoic Husband — Knowledge Bundle

This bundle is the book's knowledge layer: one markdown file per knowledge
unit, each with typed frontmatter and cross-links, per the
[Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
spec adapted at `.claude/OKF.md`.

It supersedes `sources/evidence-library.md`, which has been replaced with a
tombstone pointing here. `sources/` remains raw intake only
(`author-notes.md`, `audience-signals.md`, `interviews/`, `articles/`); this
bundle is the curated, atomized result.
