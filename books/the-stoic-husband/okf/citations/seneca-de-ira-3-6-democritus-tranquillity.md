# What It Establishes

That the "do few things and be tranquil" maxim belongs to Democritus is not
an invention of modern translators. Seneca, writing in the first century and
inside this book's own tradition, states it and names him. So does Seneca's
separate note that Democritus wrote the treatise on euthymia, the calm
steadiness of mind.

# How Ch12 Could Use It

Only if the author wants to keep Democritus's name. The cheap repair is to
drop the name (see the defect file). If he wants it, this is the honest
route: Marcus is reworking a maxim old enough that Seneca had already quoted
it and named its author. That is one clause, and it is true.

It is also a second classical citation in a chapter whose archetype sets
